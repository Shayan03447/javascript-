# JavaScript Fundamentals – Practice & Projects 🚀

This repository contains **practical code and real examples** to learn and master the fundamentals of JavaScript — from basic syntax and control flow to DOM interaction and mini projects.

It was created as part of the **AIRBRIDGE DEV** assignment to help learners build a strong foundation in core JavaScript concepts through real hands‑on practice.

---

## 🧠 What You’ll Learn

This repo focuses on key JavaScript skills including:

- 🔹 Basic syntax & variables  
- 🔹 Control flow (if/else, loops)  
- 🔹 Functions & scope  
- 🔹 DOM manipulation  
- 🔹 Projects & hands‑on examples  
- 🔹 JavaScript fundamentals for real coding tasks

Each folder contains code examples and explanations so you can run and experiment easily.
